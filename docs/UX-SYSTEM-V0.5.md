# My Dose V0.5 — UX System Overhaul

## Goal
Move the leadership demo from a responsive card-based website toward a polished mobile health/member app.

## Reference principles
The UX direction synthesizes patterns from adjacent health, wellness and subscription products rather than copying any one competitor:
- Health apps: summary-first dashboards, longitudinal progress, progressive disclosure.
- Care/subscription apps: treatment/product information, shipment status and plan controls inside one member environment.
- Premium supplement brands: strong product photography, editorial education and calm commerce surfaces.
- Dose: existing cream/green/gold visual system, editorial serif hierarchy, product imagery and science-forward positioning.

## Navigation
Primary mobile navigation is now:
1. Today
2. Learn
3. Progress
4. Plan
5. You

Secondary destinations such as science, ingredients, rewards, referrals, orders, FAQs and support live beneath these primary areas rather than competing for persistent navigation.

## Design-system decisions
- Mobile-first app shell with a 760px demo maximum width.
- 20–24px mobile gutters.
- 48px major section rhythm.
- 14–18px card/rail gaps.
- 20–28px radii on primary surfaces.
- Fewer visible borders; hierarchy comes from whitespace, surface color, photography and elevation.
- Horizontal content rails reduce vertical stacking and make the experience feel app-native.
- One dominant action per major module.
- Sticky top app header and persistent five-item bottom navigation.
- Dose brand tokens remain the source palette: cream #FBF7EE, green #425941, ink #22211C, gold #B08D57, sage #DDE3D7.

## Today
Hierarchy:
- Personal greeting + journey day
- Dominant daily adherence action
- Horizontally scrollable journey metrics
- Continue Learning editorial hero
- Compact upcoming shipment utility

## Learn
- Large program hero
- Horizontal lesson rail
- Completion state and progress
- Immersive article/lesson view
- Secondary science/ingredient discovery
- Current V0 uses the representative Liver Masterclass documented in EDUCATION-V0.md.

## Progress
- 30-day adherence summary
- Visual score ring
- Daily routine calendar
- Streak and education completion
- Insight module
- Future: check-ins and biomarker data

## Plan
- Product-led subscription summary
- Next shipment/date
- Skip shipment
- Add to next order
- Care/support
- Future: native Skio/Shopify actions

## You
- Account and secondary-navigation hub
- Plan, education, rewards/referrals, orders, help, science/ingredients

## Demo-state principle
V0.5 remains a leadership prototype. Transactional controls and health metrics are simulated unless explicitly connected later. Public Dose imagery may be used for internal demonstration, while final production assets/content require approved sources.
